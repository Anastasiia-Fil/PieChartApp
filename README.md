# Pie Chart Application

A simple C# Windows Forms application developed for the Rapid Application Development course.

### Features
- Custom pie chart control using GDI+
- Add categories and numerical values
- Automatic percentage calculation
- Color-coded chart sections with a legend
- Clear all data

### Technologies
- C#
- Windows Forms (.NET Framework)
- GDI+

### Project Structure
- `Form1.cs` — User interface and input handling
- `ChartItem.cs` — Data model
- `PieChartControl.cs` — Custom chart drawing control
